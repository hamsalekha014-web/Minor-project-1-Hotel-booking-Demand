# Hotel Booking Data Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on a hotel booking dataset using Python. The analysis focuses on understanding the structure and quality of the data, identifying patterns, analyzing booking behavior, and visualizing important relationships between variables.

## 🎯 Objectives

- Understand and explore the hotel booking dataset
- Identify and handle duplicate records
- Check and handle missing values
- Clean the dataset where necessary
- Analyze categorical and numerical variables
- Study distributions and identify outliers
- Perform univariate, bivariate, and multivariate analysis
- Analyze correlations between numerical variables
- Create meaningful visualizations
- Extract key insights from the dataset

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## 📊 Dataset

**Dataset:** Hotel Booking Demand

The dataset contains information about hotel reservations, including hotel type, booking details, arrival information, customer details, market segments, room information, cancellation status, and pricing.

## 🔍 Analysis Performed

The project includes:

1. Dataset loading and exploration
2. Dataset structure and statistical summary
3. Duplicate record analysis
4. Missing-value analysis
5. Data cleaning
6. Categorical analysis
7. Numerical analysis
8. Outlier detection and handling
9. Univariate analysis
10. Bivariate analysis
11. Multivariate analysis
12. Correlation analysis and heatmap
13. Key insights and observations
14. Final conclusion
